# Chart.js Progress Bar Chart

A horizontal bar chart styled as progress bars, built with Chart.js 3.8.0 in plain HTML, CSS and JavaScript. Bars are thin, fully rounded and the legend is hidden.

## Getting started

Open `index.html` in your browser. No build step or installation is needed, Chart.js is loaded from a CDN.

## Project structure

```
.
├── index.html
├── style.css
└── script.js
```

`script.js` is split into three blocks: data, config and render.
